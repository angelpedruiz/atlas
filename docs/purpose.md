# Purpose

Agreed statement of what Atlas is. Change it only when the owner and the agent agree.

Atlas is a personal, timeless graph of concepts. Its job is to commit your own understanding to long-term memory, so you come back to your own explanation instead of a random source. Each concept is a single, flexible Markdown file in your words and house notation. Only a small core is required: frontmatter with a one-sentence essence, aliases, domains, status and typed relations to other concepts, plus a short intuition. Core math, relations prose, an implementation, open questions and visuals are all optional and can grow over time. Within the text, other concepts are linked inline wherever they’re mentioned, with display text worded to fit the note at hand, such as [[particle-filter|sampling]] or [[gaussian-conditioning|conditioning a big Gaussian]], while the link always lands on the one canonical note. A visual, when present, is a viz code block inside the same file that calls the note’s own implementation. A build step turns it into a static SVG, and into a live widget when it’s tagged interactive. All of it lives in a plain-text Git repo, so the history doubles as the record of how your understanding evolved. That repo feeds three surfaces. Obsidian is where you edit, on desktop and phone, and its reading view hides plotting code and shows the static pictures. An Atlas site, which also works from the phone’s home screen, gives a clean reading mode with live interactive plots and the graph. A command-line tool with a JSON export lets coding agents search, create, connect and update concepts. Agents propose changes and never rewrite your intuition.
