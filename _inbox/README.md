# Inbox

Drop raw captures here: lecture snippets, paper excerpts, photos of whiteboards,
half-formed thoughts. Anything goes; nothing here is part of the graph.

Processing (by you or an agent, see `AGENTS.md`): extract the concepts, run
`atlas find` for each, extend or create notes in `concepts/`, link them, and
delete the capture in the same commit. Git keeps the original.
